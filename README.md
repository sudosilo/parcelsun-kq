Parcelsun

Parcelsun is a heat model for a parcel locker sitting in the sun, for anyone studying how hot a locker gets.

It models solar heat on the locker with a four module default and a field style locker look. It shows a board strip, hat shadow, console gear heat, and a back view. Version four added even service seams, IT cabinet louvers behind the screen, and console panel detail.

Latest change. 2026-11-12, v2026.11.12. The starter module is now two columns like every real module: a screen column with doors above and below the screen and keypad, beside a full column of doors. Screen column picks the side. The old single wide starter column is gone. A locker from Field Twin can carry oversize Q modules, which land on the right end of the bank.
